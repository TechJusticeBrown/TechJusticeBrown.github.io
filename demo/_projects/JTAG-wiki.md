# Inspiration
The World Wide Web was begun by CERN (the European Council for Nuclear Research) to handle the constant issue of needing to re-educate new researchers, making sure researchers were on the same page, and allowing researchers to collaborate across disciplines more effectively. [Hypertext systems](https://en.wikipedia.org/wiki/Hypertext) allow users to quickly navigate between related nodes (pages) using links (e.g., the `<a>` tag). This meant that related content was quickly and easily accessible for new researchers and allowed current researchers to collaborate more effectively.
We will do the same at JTAG. This website shall serve as a wiki to help us organize and work on projects as well as an example to new individuals of what our organization is about.

# Intro Project
Everyone will write a 250-500 word post about  

1) something related to tech justice that fascinates you. For example, you might write about [the tucson mesh grid](https://www.tucsonmesh.net/).  
2) A project proposed by someone else that you found interesting  

These posts will be uploaded to the website and used as an opportunity to create a shared vision for what projects we want to take on.

# GitHub Guide
GitHub is a tool for collaboration and version control. It enables easier examination of changes, revisions, and exploration for ongoing projects. Projects are typically built within a single repository.
